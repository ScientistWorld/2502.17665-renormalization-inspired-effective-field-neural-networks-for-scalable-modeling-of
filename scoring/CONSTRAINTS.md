# Scientist Constraints

## Data
Use only the deterministic splits generated by `data/three_spin.py`: 16,000 training samples and 4,000 test samples for each task, with 15 lattice sites and the fixed coupling seed. The test split must not be used for training or model selection.

## Model Scale
For the binary task, keep the reported width at or below 105 neurons when comparing against the `three_spin_binary` target. For the continuous task, keep the reported width at or below 150 neurons. Increasing width is resource scaling, not a methodological improvement.

## Evaluation
Write prediction artifacts with `y_true` and `y_pred` arrays and score them through `scripts/evaluate.sh`. The evaluator must remain independent of method code.

## Compliance Checklist
- [ ] Used the fixed generated train/test splits from `data/three_spin.py`
- [ ] Did not train on the test split
- [ ] Binary submission reports `neuron_count <= 105`
- [ ] Continuous submission reports `neuron_count <= 150`
- [ ] Scores were produced by `scripts/evaluate.sh`
